Specialist: Security

Status: starting

The Security specialist is a long-lived agent at AgentiCCells, named specialist.security@AgentiCCells.dinis. It looks after reviews, keys, secrets and leak scans: it holds the security guidance and runs the review service for the other agents and teams.

What it is

The specialist works alongside every other agent with the same or a compatible focus, offering guidance and reviews. It does not do other teams' work. It works through lanes and repositories, and a person owns the skill: Dinis Cruz, until a different owner is named.

The idea is set out in the article Specialist agents for every team.

What a team gets from it

  • A bootstrap pack. New teams start with a pack of security guidance from the specialist.
  • A review on request. A team can ask the specialist to review its work.
  • Comments. The specialist comments on pull requests and drafts.
  • Guidance kept current. The specialist keeps the security guidance up to date.
