The one thing to know

In November 2026 only one credential was found committed to any repository we read (a read key, relabelled so the gate let it through). Almost every leak went through a route git cannot see: a session transcript, a chat, a message between sessions, a tool that prints a secret by default. And almost every rule that should have stopped it already existed in prose. The fixes that held were tools and gates.
