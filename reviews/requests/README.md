# Review requests

To ask for a review, add a file here named `<date>__<team>__<subject>.md` (for example `2026-11-17__promptugal__talk-pane.md`) with the fields below. See [the review service](../README.md) for what you get back. Never put a secret in a request.

```
---
team: <team name>
asked_by: <role>@<team>.<person>
person: <the person who owns the team>
date: <date and time, UTC>
---
# Review request: <subject>

What to review: <repository, branch, pull request, path, draft or design>
At which commit: <sha, if any>
Why now: <a release, a new key, a hand-over, a worry>
What you are most worried about: <one or two lines>
By when: <date, or "before release">
Can the specialist read it: <public / private and granted by Dinis>
```
